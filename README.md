# Bajrang Medicose

A responsive, single-page storefront prototype for a neighborhood pharmacy and diagnostics service. Customers can browse medicine and wellness essentials, manage a shopping bag, request prescription assistance, and request blood-test bookings with home sample collection.

## Run locally

Open `index.html` in any modern browser. No build tools or dependencies are required. Google Fonts are loaded over the internet; system sans-serif fallbacks are included.

## What's included

- Searchable medicine catalog with category filters and add-to-bag controls.
- Shopping bag with quantity controls and subtotal.
- Blood-test cards and a home collection booking form with date, time, address, and contact fields.
- Prescription-assistance callback form.
- Responsive desktop and mobile layouts.

## Prototype limitations

This is a frontend-only demonstration. Orders and booking requests are not transmitted, saved, or confirmed. Product listings and prices are sample data; update them with pharmacy-approved information. Before accepting real orders, connect a secure backend, payment and order workflow, inventory, lab scheduling, service-area checks, and appropriate privacy/security safeguards. Prescription handling and diagnostic services should be reviewed with qualified local professionals and applicable regulations.
